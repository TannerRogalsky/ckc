A floating city that grows as more boats attach to it. A typical pirate gathering place, heavily trafficked with ships flying bright colors. Some ships are anchored into a continental shelf that never surfaces — a lacuna.

### Notable Locations
- [[The Brine & Bodak]] — Run by [[Transel]]; [[Octavia Crayborne]] formerly performed there
- [[The Bad Hare Day Theatre]] — Run by [[Vorgan of the Stage]]
- [[The Boardwalks]] — Run by [[The Marid]]; where the party recruited [[Otto]]
- [[The Corsairs' Court]] — Run by [[Octavia Crayborne]]
- [[The W. H. Boutique]] — Run by [[The Wonder Hulk]], a well-traveled proprietor
- [[Savar Brews]] — Run by [[Gilder Savar]], now a lich
- [[Bookbinders Cray]] — Run by [[Pleasance MacLenth]]
- [[The Church of the Thirty Lights]] — Run by [[Pastor Borm]], a gold wyrmling
